Sơ đồ màn hình GoWander

Mục lục cho người và agent. Mỗi thẻ là một màn: tên, file nguồn trong canvas (project/…), giai đoạn phát hành và mục đích. Thứ tự cụm giống thứ tự hàng trên canvas. Số liệu và nội dung trong bản vẽ là DEMO; ảnh thật có nguồn Wikimedia Commons.

Luồng chính · mở màn nào từ đâu

  • Mở Câu chuyệnMain → Khám phá (tab) → ô “Câu chuyện Sài Gòn” hoặc danh mục “Lịch sử” → StoryList → StoryReader → “Đi tới đây” → RouteResults
  • Mở Khám phá Việt NamMain → Khám phá (tab) → ô “Khám phá Việt Nam” → ExploreVietnam → chọn vùng → StoryList
  • Tìm theo loạiMain: chip “Quán ăn” / “Bệnh viện” (hoặc Search → Tìm theo loại) → SearchFood / SearchHospital → PlaceDetail → Booking (nếu quán nhận đặt bàn)
  • Đặt bàn + mónPlaceDetail → Booking: ngày, giờ, số người, món (tuỳ chọn) → cọc theo chính sách quán (PartnerBooking)
  • Đăng ký appLogin → MobileRegister → MobileVerifyEmail → Settings
  • Quên mật khẩu appLogin → MobileForgotChannel → MobileForgot → MobileResetPassword
  • Admin đăng nhậpAuthAdminLogin → AuthAdmin2FA → AdminOverview (lỗi: AuthAdminError, AuthAdminLocked; lần đầu: AuthAdminInvite)
  • Đăng ký hợp tácShowcase / AuthPartnerLogin → PartnerApply → PartnerApplyDocs → PartnerApplyReview → PartnerApplyPending (email đã nhận) → duyệt ở AdminPartnerRequests → email kích hoạt hoặc PartnerApplyFix
  • Cấp tài khoản quánAdminPartnerRequests (hoặc Admin tự tạo) → AdminPartnerCreate → lời mời email/SMS → chủ quán đặt mật khẩu → PartnerDashboard → PartnerStaff: chủ quán mời Quản lý / Nhân viên
  • Nhân viên quán trên appSettings → Quán của tôi (MyShops) → ShopInvite (lần đầu) → ShopToday → ShopOrderDetail / ShopMenuQuick / ShopStatus
  • Khách xem/huỷ đặt bànSettings → MyBookings → BookingCancel
  • Partner đăng nhậpAuthPartnerLogin → PartnerDashboard (quên: AuthForgotChannel → AuthForgotCode → AuthForgotReset)
